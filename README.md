# Neon Breakout

A responsive, dependency-free browser game built for Lab 1 of the Agentic Programming course (67723) at Hebrew University.

## Run locally

Open `index.html` directly in a modern browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Keyboard: Arrow keys or A/D to move, P or Escape to pause, Space to start.
- Mouse: Move over or drag on the game canvas.
- Touch: Drag on the canvas or use the on-screen controls.

## Hosting

The project uses only HTML, CSS, and JavaScript and is compatible with GitHub Pages. No build step, backend, API, or external asset is required.
